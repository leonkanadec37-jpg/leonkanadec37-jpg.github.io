# Правила проекта Livi Jewelry для AI-ассистента

## Добавление и синхронизация товаров

1. **Защита от дубликатов (СТРОГОЕ ПРАВИЛО)**:
   - Никогда не добавлять товары повторно, если они уже есть в каталоге `products.json`.
   - Проверка дубликатов производится:
     * **По фотографии**: перцептивный хэш / сравнение миниатюр (`diff < 12.0`). Если фотография визуально совпадает с уже существующим товаром, добавление автоматически пропускается.
     * **По названию и цене**: если нормализованное название и цена совпадают с имеющимся товаром, он пропускается.
   - Пользователю всегда выводится отчет: какие товары были добавлены, а какие пропущены как дубликаты.

2. **Готовые команды для работы**:
   - **Массовая выгрузка / синхронизация из Google Drive**:
     ```bash
     python sync_drive.py "https://drive.google.com/drive/folders/ID" --commit --push
     ```
     Скрипт автоматически скачивает файлы, отсекает дубликаты, оптимизирует фотографии в WebP, обновляет `products.json` и микроразметку `shop.html`, делает git commit и push.

   - **Синхронизация из локальной папки**:
     ```bash
     python sync_drive.py --local-folder "path/to/folder" --commit --push
     ```

   - **Одиночное добавление товара**:
     ```bash
     python add_product.py --image path.jpg --title "Название" --category Necklaces --price 25000 [--commit] [--push]
     ```
     Скрипт `add_product.py` также автоматически проверяет дубликаты перед добавлением. Для принудительного добавления есть флаг `--force`.

3. **Стандарты медиафайлов**:
   - Все фотографии конвертируются в формат **WebP** (качество 82, метод 6).
   - Обязательно применяется `ImageOps.exif_transpose(im)` для сохранения правильной ориентации фото со смартфонов.
   - Пропорции карточек: вертикальные (3:4, max 1440x1920).

4. **Двусторонняя синхронизация (удаление товаров)**:
   - Если товар, привязанный к Google Диску (`drive_id`), был удален из папки на Диске, `sync_drive.py` автоматически удаляет его из `products.json` и с сайта, а также удаляет связанный файл из `assets/`.
   - Товары, добавленные вручную (без `drive_id`), никогда не затрагиваются при удалении.

5. **Правило соответствия цен и детального описания комплектов**:
   - Описание товара на сайте должно полностью соответствовать фактической цене.
   - Для товаров-комплектов (где на фото представлено несколько изделий, например колье, браслет, серьги, кольцо):
     * В поле `price` (цена карточки) указывается **полная стоимость комплекта** (сумма всех элементов).
     * В поле `description` **обязательно детально расписывается стоимость каждого элемента по отдельности** (например: *«В комплекте: Колье — 40 000 тг, браслет — 10 000 тг, серьги — 10 000 тг. Полная стоимость комплекта — 60 000 тг. Каждое изделие можно приобрести по отдельности или полным сетом.»*).
     * Если в названии есть пометка «под заказ», она сохраняется в названии карточки и описании: *«(под заказ)»*.
     * Категория для таких товаров назначается `Sets` (Комплекты).
