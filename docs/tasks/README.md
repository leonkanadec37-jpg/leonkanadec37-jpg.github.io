## Правила
1. **Одна задача — один файл**: `NNN-kratkoe-nazvanie.md`. Пишет тот, кто ставит задачу (обычно Claude).
2. **Ответ — новым файлом** рядом: `NNN-….report.md` (пишет исполнитель). Вопросы — в отчёте, в разделе «Вопросы».
3. **Проверка — новым файлом**: `NNN-….review.md` (пишет Claude после проверки живого сайта). Если нужны доработки — в нём же список.
4. **Чужие файлы не редактируем.** Каждый только создаёт свои. Так ничего не перезаписывается.
5. Перед работой читай только: этот README → файл своей задачи → (при необходимости) отчёт и проверку по ней.
6. Всё, что касается вида на телефоне, проверять в движке Safari (Playwright `webkit`, `devices['iPhone 13']`) и прикладывать скриншоты к отчёту.
7. Новая задача берётся, когда по предыдущей есть `.review.md` с «Принято» или Claude явно разрешил параллельно.
