## 1. Что сделано

### S1. Устранение системных синих рамок Safari на iPhone
1. **`scripts/storefront-menu.js`**:
   - Перевод фокуса на первую ссылку меню (`menu.querySelector('a')?.focus(...)`) и возврат фокуса на переключатель (`trigger.focus()`) теперь выполняются **только при открытии с клавиатуры** (`isKeyboard = event.detail === 0` для клавиш Enter/Space, а также при закрытии по Escape).
   - При обычном касании (tap) или клике мышью фокус не переводится принудительно, что полностью исключило появление нативной синей рамки iOS Safari вокруг «Колье» при открытии и вокруг «Меню» после закрытия.
   - При закрытии меню по тапу на оверлей `backdrop` возврат фокуса на кнопку также отключён.
2. **`styles.css`**:
   - Внедрены фирменные стили фокуса, действующие исключительно для клавиатурной навигации:
     ```css
     :focus:not(:focus-visible) {
       outline: none;
     }
     :focus-visible {
       outline: 1px solid var(--fg);
       outline-offset: 3px;
     }
     button, a, summary, [role="button"] {
       -webkit-tap-highlight-color: transparent;
     }
     ```
   - Нажатие Tab на компьютере отображает тонкую тёмную рамку (`1px solid var(--fg)` с отступом `3px`), а тапы на iPhone остаются чистыми без системных артефактов.

### S2. Меню: замена браузерных маркеров «▸» на тонкие шевроны
1. **`styles.css`**:
   - Для пунктов меню `<details>` («Другие категории» и «По материалу») убран стандартный треугольный браузерный маркер:
     ```css
     .storefront-more-types > summary,
     .storefront-materials > summary {
       list-style: none;
       font-size: 13px;
       font-weight: 500;
       letter-spacing: normal;
       text-transform: none;
       cursor: pointer;
       display: flex;
       align-items: center;
       justify-content: space-between;
       min-height: 44px;
       color: var(--fg);
       -webkit-tap-highlight-color: transparent;
     }
     .storefront-more-types > summary::-webkit-details-marker,
     .storefront-materials > summary::-webkit-details-marker,
     .storefront-more-types > summary::marker,
     .storefront-materials > summary::marker {
       display: none;
     }
     ```
   - Добавлен тонкий шеврон справа (`::after`), идентичный переключателю «Меню ⌄», который плавно поворачивается на 180° при раскрытии (`[open] > summary::after { transform: rotate(225deg); }`).
   - Снято принудительное `text-transform: uppercase` с пункта «По материалу»: теперь оба аккордеона оформлены единообразно в строчном регистре (sentence case), гармонируя с соседними пунктами «Доставка и оплата», «Весь каталог».

### S3. Компактный каталог на мобильном: шторка фильтров и подъём карточек

   - Оставлены на первом экране:
     1. Поисковая строка (`#searchInput`).
     2. Горизонтальный скролл категорий (`.filters`: Все, Колье, Серьги, Браслеты, Комплекты, Кольца, Сотуары, Цепи).

2. **Нижняя шторка «Фильтры и сортировка» (`#filterSheetModal`)**:
   - Реализована в дизайне Haute Joaillerie (выезжает снизу с backdrop-блюром, закруглением `16px 16px 0 0`, анимацией `filterSheetSlideUp` и поддержкой `env(safe-area-inset-bottom)`):
     - **Сортировка**: чипсы «По популярности», «Сначала новинки», «Цена: по возрастанию ↑», «Цена: по убыванию ↓».
     - **Стоимость**: чипсы «Все цены», «до 25 000 ₸», «25–50 000 ₸», «от 50 000 ₸».
     - **Камни и вставки**: интерактивные чипсы «Все камни», «Барочный жемчуг», «Малахит», «Розовый кварц», «Гранат», «Аметист», «Бирюза», «Горный хрусталь», «Гематит», «Лунный камень», «Жемчуг Майорка», «Коралл и Яшма», «Лазурит», «Тигровый глаз».
     - **Фиксированный футер**: кнопка «Сбросить» и основная кнопка с динамическим счётчиком («Показать N украшений»).
3. **Строка активных фильтров (`#activeFilterChips`)**:
   - При выборе параметров в шторке под тулбаром появляются аккуратные чипсы с крестиком (например, `[ до 25 000 ₸ ✕ ]`, `[ Барочный жемчуг ✕ ]`, `[ Цена: по возрастанию ✕ ]`).
   - Клик по крестику на любом чипсе моментально сбрасывает соответствующий фильтр.
4. **Метрика высоты первого экрана (390×844 / 390×664 в Playwright Safari)**:
   - Верх первой карточки товара (`#grid .card`) теперь начинается на **325.2 px** от верха экрана (**49.0%** от высоты вьюпорта Safari 664 px, и **38.5%** от физического экрана iPhone 13 844 px).
   - **Цель достигнута**: верх карточек находится выше 50% экрана, на первом экране покупатель сразу видит фото изделий.
5. **Десктопная версия осталась нетронутой**:
   - Все новые мобильные элементы скрыты на экранах $> 768$ px (`display: none !important;`).
   - Тулбар со счётчиком, кнопками цен, селектом сортировки и горизонтальной плашкой камней на компьютере работает в исходном виде.
