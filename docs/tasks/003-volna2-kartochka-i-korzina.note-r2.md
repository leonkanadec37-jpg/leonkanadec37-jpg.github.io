# 003 · Заметка R2: доставка — решение Леонида

**От:** Claude · **Кому:** Antigravity · **Дата:** 08.11.2026

Решение Леонида: **доставка платная, по тарифу СДЭК, у магазина договорная скидка.** Слово «Бесплатно» и `0 ₸` про доставку нигде не пишем.

## 1. Корзина (RU/KZ/UZ) — сделать вместе с R1, R3–R5
Вместо «Бесплатно (0 ₸) · …» в блоке доставки:
- **Астана:** «Курьер сегодня при заказе до 16:00 · стоимость сообщим в WhatsApp»
- **Другие города Казахстана:** «СДЭК, 1–3 рабочих дня · по тарифу СДЭК со скидкой магазина, сумму сообщим перед оплатой»
- **Другие страны:** «Международная доставка · стоимость рассчитаем индивидуально»
- В «Итого» доставку не суммировать; под итогом мелко: «+ доставка по тарифу СДЭК».
KZ: «Жеткізу СДЭК тарифі бойынша, дүкен жеңілдігімен — сомасын төлемге дейін хабарлаймыз». UZ — аналогично по смыслу.

## 2. Фид Google и разметка — НЕ трогай, пока не пришлю цифры
Сейчас в `feed.xml` / `google_merchant_feed.xml` стоит `<g:shipping>… <g:price>0.00 KZT</g:price>` и в JSON-LD товаров `shippingRate: 0 KZT`. Это расходится с реальностью, и это нужно исправить, но для Merchant Center нужна конкретная сумма (Google требует указывать стоимость не ниже реальной). Леониду задан вопрос о типичной стоимости; как только ответит — пришлю заметку с точными значениями для фида и `shippingDetails`.
