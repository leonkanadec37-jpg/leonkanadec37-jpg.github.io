### Рекомендации по кэшированию для Леонида (при подключении Cloudflare)
Поскольку GitHub Pages управляет заголовками самостоятельно и отдаёт дефолтный `max-age=600` (10 минут), при подключении бесплатного или платного тарифа Cloudflare рекомендуется настроить следующие Page Rules / Cache Rules:
1. **Статика (`/assets/*`, `*.webp`, `*.svg`, `*.png`, `*.mp4`, `styles.css`)**:
   - `Edge Cache TTL`: 1 месяц (или 1 год)
   - `Browser Cache TTL`: 1 месяц
2. **HTML-страницы (`livijewelry.kz/*`)**:
   - `Edge Cache TTL`: 2 часа (с автоматической очисткой через Cloudflare API при деплое)
   - `Browser Cache TTL`: 10 минут
3. **Корзина (`/cart.html`, `/kz/cart.html`, `/uz/cart.html`)**:
   - `Bypass Cache` (не кэшировать на Edge).
