## S1. Синие прямоугольники вокруг «Колье» и «Меню»
`scripts/storefront-menu.js`: при открытии меню `menu.querySelector('a').focus(...)`, при закрытии `trigger.focus()`. Своих стилей фокуса нет, поэтому Safari рисует системную синюю рамку: вокруг «Колье» при открытом меню и вокруг «Меню» после закрытия.
**Исправить:**
- Переводить фокус в меню и возвращать на кнопку **только при открытии с клавиатуры** (Enter/Space/Escape). При касании или клике фокус не трогать.
- В `styles.css` фирменный фокус только для клавиатуры:
```css
:focus:not(:focus-visible) { outline: none; }
:focus-visible { outline: 1px solid var(--fg); outline-offset: 3px; }
```
Проверить также кнопки корзины, мини-корзину, чипсы и поля — нигде не должно быть синей системной рамки после касания.

## S2. Меню: стандартные треугольники «▸»
В мобильном меню «▸ Другие категории» и «▸ ПО МАТЕРИАЛУ» — это стандартные маркеры `<details>` браузера (в каталоге их уже заменили, в меню — нет). Убрать маркер (`summary { list-style: none } summary::-webkit-details-marker { display: none }`) и поставить тонкий шеврон справа, как у «Меню ⌄», с поворотом при раскрытии. Оба пункта оформить одинаково (сейчас один строчными, другой капсом) — строчными, как «Доставка и оплата».

## S3. Каталог на телефоне: фильтры занимают почти весь первый экран
Сейчас при 390×844 до первой карточки идут: заголовок, подзаголовок, поиск, категории, «По камням», счётчик, 4 кнопки цены, сортировка — первая карточка начинается на ~680 px, на iPhone видно только верх двух фото. Метка «ПО КАМНЯМ:» стоит ниже центра чипсов, между рядами большие пустые промежутки.
**Сделать (только ≤ 768 px):**
- Оставить на экране: поиск, ряд категорий и одну строку «**74 украшения · Фильтры (иконка) · Сортировка**».
- Камни, цена и сортировка — в нижней шторке «Фильтры» (как мини-корзина: выезжает снизу, safe-area, кнопка «Показать N украшений» внизу, «Сбросить»). Выбранные фильтры показывать чипсами под строкой с крестиком.
- Подзаголовок «Авторская коллекция…» на мобильном убрать или сократить до одной строки.
- Отступы между блоками до списка товаров — 16–24 px.
- **Цель:** верх первой карточки не ниже 50 % высоты экрана на 390×844 (сейчас ~80 %).
На компьютере всё оставить как есть.
