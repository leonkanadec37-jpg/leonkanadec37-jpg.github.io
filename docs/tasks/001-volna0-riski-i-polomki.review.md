## На доработку: T-P0.4 — меню на телефоне
**Воспроизведение** (`/shop.html`, так же на всех страницах с шапкой `storefront`: главная, каталог, карточки):
1. Ширина 375 px, прокрутить вниз (`scrollY = 900`).
2. Нажать «Меню».
3. Результат: страница затемняется, **шапка и меню исчезают** — `nav.storefront-menu` оказывается на `top: -843px` (выше экрана). Прокрутка заблокирована, кнопки «Меню» не видно. Покупательница видит серый экран и не понимает, как выйти.

На хабах (`/kolye-iz-zhemchuga.html`, боковая шторка `position: fixed`) всё работает — проблема только у `storefront-menu`.

**Причина:** правило `body.drawer-open { overflow: hidden }`. Когда у `body` появляется `overflow: hidden`, `body` становится контейнером прокрутки для липкой шапки (`header { position: sticky }`); шапка возвращается на своё место в начале документа, а меню (`position: absolute; top: 57px` относительно шапки) уезжает вместе с ней наверх.

**Как исправить:**
- Блокировать прокрутку только на `html`: `html.drawer-open { overflow: hidden; }`. Правило для `body.drawer-open` (и `body.modal-open`) убрать — на `body` оставить только скрытие плавающей кнопки WhatsApp, как было.
- Надёжнее дополнительно сделать меню фиксированным: `.storefront-menu { position: fixed; top: <высота шапки>; left: 0; bottom: 0; overflow-y: auto; overscroll-behavior: contain; }` (на мобильном), чтобы оно не зависело от того, где шапка.
- Проверить: прокрутить каталог вниз → «Меню» → шапка и меню на месте, фон не прокручивается → закрыть → страница на той же позиции.
